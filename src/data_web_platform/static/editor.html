编辑数据集

组合修改任务、筛选轨迹、移除字段和调整视频，生成新的数据集。

1. 选择数据集

可先在工作台“数据集”页登记已有 v2.1 / v3.0 目录。

编辑保持源版本、FPS 和保留轨迹的帧数。所有 episode ID 均指编辑前的编号；输出会重新连续编号。

3. 字段与相机

勾选要从输出移除的字段。删除相机也会移除对应视频和统计；系统索引不可删除。

4. 视频处理

关闭时尽量复用视频；删除 v3.0 轨迹时，上游可能需重封装或转码，预览计划会说明。

同时留空保留原尺寸；填写后精确缩放到指定宽高，可能改变长宽比。

必须使用新目录。原始数据不被覆盖。输出不复制自定义附属文件，包括已有 Annotation 标注；原数据集及标注保留。

执行资源
